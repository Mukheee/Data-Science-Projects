# Health Data Dashboard

## 📌 Overview
This project processes health data and presents key insights through an interactive dashboard to track metrics and trends.

## 🎯 Problem Statement
Convert raw health data into meaningful insights and visual reports for decision-making.

## 📂 Dataset
- Health-related dataset with multiple indicators

## 🧹 Data Cleaning & Preprocessing
- Handled missing values
- Standardized data formats

## 📊 Dashboard Features
- Visualization of key health metrics
- Trend analysis over time
- Interactive filters for exploration

## 📈 Key Insights
- Identified trends in key health indicators
- Highlighted patterns useful for decision-making

## 🛠 Tools & Technologies
- Power BI
- Excel

## 🚀 How to Run
1. Open the Power BI file
2. Interact with the dashboard
