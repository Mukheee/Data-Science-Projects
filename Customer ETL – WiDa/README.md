# Customer Data ETL Pipeline

## 📌 Overview
This project implements an end-to-end ETL pipeline to extract, clean, and store customer transaction data for analytics and reporting.

## 🎯 Problem Statement
Transform raw customer transaction data into a structured format suitable for analysis.

## 🔄 ETL Process
### Extract
- Loaded raw customer transaction data

### Transform
- Cleaned missing values
- Standardized formats
- Resolved inconsistencies

### Load
- Stored processed data for reporting and analytics

## 📊 Outcome
- Reliable and structured dataset ready for downstream analysis

## 🛠 Tools & Technologies
- Excel
- SQL
- Looker
- Power BI

## 🚀 How to Run
1. Open Excel/SQL files
2. Follow transformation steps
