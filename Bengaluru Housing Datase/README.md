# Bengaluru House Price Prediction

This project predicts house prices in Bengaluru using machine learning.

## Problem
Build a model to estimate house prices based on features like location, square footage, and number of bathrooms.

## Key Steps
- Cleaned messy data (e.g., range values in sqft)
- Engineered features like price per sqft
- Reduced location dimensionality
- Applied one-hot encoding
- Built a Linear Regression model

## Results
The model performs well overall but shows higher errors in less frequent locations.

## Tools
Python, Pandas, NumPy, Scikit-learn
